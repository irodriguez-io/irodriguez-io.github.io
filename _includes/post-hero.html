{%- comment -%} post-hero.html -------------- Renders a topic-relevant hero image for a blog post. Inputs (read from `page`): page.topic — semantic tag: iam, infosec, cybersec, data-security, automation, networking, generic. Optional; falls back to "generic" if missing. page.image — optional manual override (e.g. /img/special.png). Wins over the pool entirely. Pool data: site.data.images.images (auto-generated by tools/fetch_blog_heroes.py) Selection is deterministic — based on the post's Unix timestamp plus slug length — so the same post always renders the same image, and EN/ES versions sharing a slug + date land on the same image. Pure Liquid; works on vanilla GitHub Pages (no plugins). {%- endcomment -%} {%- if page.image -%} {%- else -%} {%- assign topic = page.topic | default: "generic" -%} {%- assign filtered = site.data.images.images | where_exp: "img", "img.topics contains topic" -%} {%- if filtered.size == 0 -%} {%- assign filtered = site.data.images.images | where_exp: "img", "img.topics contains 'generic'" -%} {%- endif -%} {%- if filtered.size == 0 -%} {%- assign filtered = site.data.images.images -%} {%- endif -%} {%- if filtered.size > 0 -%} {%- assign ts = page.date | date: "%s" | plus: 0 -%} {%- assign slug_for_size = page.slug | default: page.id -%} {%- assign slug_len = slug_for_size | size -%} {%- assign seed = ts | plus: slug_len -%} {%- assign idx = seed | modulo: filtered.size -%} {%- assign chosen = filtered[idx] -%} {%- endif -%} {%- endif -%}
