{%- comment -%} rain.html --------- Decorative background rain. Static pool of 24 drops, animated entirely in CSS; see .rain in css/base.css. No JS, no DOM churn after first paint. Each drop gets its horizontal position, size, duration and a negative delay from the loop index, so the pool looks random but renders identically on every build. The negative delay starts each drop partway through its cycle, which avoids all 24 falling in lockstep on load. {%- endcomment -%}
